## Notas de implementação

- Instalar plugin **Yoast SEO** ou **Rank Math** para gerenciar tags via painel WordPress
- Configurar breadcrumbs schema em todas as páginas internas
- Verificar via Google Search Console após publicação
- Testar rich results com: https://search.google.com/test/rich-results
